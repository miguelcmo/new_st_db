# Streamlit + InfluxDB Dashboard

A simple web dashboard built with **Streamlit** that connects to an **InfluxDB** database to visualize sensor data.

---

## 🚀 Features

- Connects to an InfluxDB instance  
- Queries and displays time-series data  
- Basic visualization with Streamlit charts  

---

## 🧰 Tech Stack

- [Streamlit](https://streamlit.io/) – for the web interface  
- [InfluxDB](https://www.influxdata.com/) – for time-series storage  
- [Python](https://www.python.org/) – project language  
- [GitHub](https://github.com/) – version control and collaboration
